# Rubric for coding the written reasons

Code each reason with one of: `scope`, `mismatch`, `none`.

- **scope**: names where the memory belongs, or the situation it came from (the scope error)
- **mismatch**: notices the reply is wrong in the memory's direction, but not why
- **none**: doesn't relate the reply to the memory

The sheet hides the memory-sources setting and shuffles the rows. Code every row before looking at any results. If possible, have a second person code them too and compare.

## S3-birthday

`scope` here means the reason says the formal-tone preference is for work (emails to a manager), not for a friend.

- scope: “The formal preference was for emailing my manager, not for Sam.”
- mismatch: “Its tone is too formal.”
- none: “I liked it.”

## S2-explain

`scope` here means the reason says the bullet-point preference is for quick lists such as essay feedback, not for an explanation asked for step by step.

- scope: “Short bullets were for my essay feedback, not for explaining things.”
- mismatch: “Too short, not enough detail.”
- none: “It answered the question.”
